## Jeden wspólny serwer MCP

- Wszystkie sesje Claude Code korzystają teraz z jednego serwera MCP wewnątrz This Is Logged. Każda sesja nie uruchamia już osobnego procesu aplikacji.
- Zakończenie aplikacji wyłącza również MCP. Samo zamknięcie okna ustawień pozostawia aplikację w menu macOS.
- Połączenie pozostaje lokalne i jest chronione tokenem dostępu. Dotychczasowe narzędzia MCP oraz zbieranie aktywności przez hooki pozostają dostępne.

Po aktualizacji uruchom ponownie otwarte sesje Claude Code, aby wczytały nową konfigurację. Do korzystania z MCP aplikacja This Is Logged musi być uruchomiona, a integracja Claude Code włączona.
