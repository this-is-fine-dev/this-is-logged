## Lżejsza integracja Claude Code

- Hooki zapisują tylko polecenia użytkownika i koniec odpowiedzi; narzędzia, odpowiedzi i zdarzenia techniczne są odrzucane przed otwarciem bazy.
- Claude ocenia wyłącznie bieżącą wiadomość i może usunąć ją jako szum bez pobierania historii dnia.
- Tekst i odpowiedzi MCP mają twarde limity, baza zachowuje maksymalnie 31 dni, a stary szum jest automatycznie usuwany.
- Dashboard tworzy wiersze tylko dla ostatnich 50 istotnych zdarzeń.
