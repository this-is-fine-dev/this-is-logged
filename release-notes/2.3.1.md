# This Is Logged 2.3.1

- Wybór kalendarza zastąpiono wyborem całego konta, np. `WP`.
- Spotkania są zbierane ze wszystkich kalendarzy wybranego konta, więc nie trzeba wiedzieć, którego używa Teams.
- Ustawienie zapisane w wersji 2.3.0 zostanie automatycznie przypisane do właściwego konta.
- Naprawiono awarię po zapisaniu ustawień, gdy wcześniej było otwarte okno analizy czasu.
