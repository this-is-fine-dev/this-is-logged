# This Is Logged 2.3.0

- Dodano integrację z lokalnym Kalendarzem macOS i wybór służbowego kalendarza w ustawieniach.
- Spotkania są przypisywane do konfigurowalnego zadania zbiorczego, domyślnie `RPR-18`.
- Anulowane, odrzucone, całodniowe, wolne wydarzenia i nieobecności są pomijane, a nakładające się spotkania nie dublują czasu.
- Rozmowy Claude Code bez osobnego zadania trafiają do zadania zbiorczego zamiast znikać jako szum.
- Dashboard oraz MCP `review_day` pokazują ten sam podział czasu wraz z nazwami i godzinami spotkań.
