## Błyskawiczna integracja z Claude Code

- Zbieranie aktywności działa teraz w tle i nie opóźnia rozpoczęcia odpowiedzi Claude'a.
- Hook nie dodaje już instrukcji do rozmowy ani nie wymusza wywołania MCP przy każdej wiadomości.
- Kolejne wiadomości w jednej sesji dziedziczą ostatnie rozpoznane zadanie, również po ręcznej korekcie.
- MCP uruchamia analizę aktywności dopiero na wyraźną prośbę użytkownika.
- Paczkowanie usuwa roboczą kopię aplikacji, więc macOS nie pokazuje duplikatów obok instalacji z `/Applications`.
